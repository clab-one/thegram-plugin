# Learn from public .gram examples

These public references illustrate authoring patterns. They are not private project facts, automatic backfill targets or proof of cloud MCP/host capability.

| Sample | Useful pattern |
| --- | --- |
| [Engineering](https://viewer.thegram.one/samples/engineering.gram) | Purpose, current architecture, meaningful development eras and unresolved work. Source-grounded counts name their definition/command; inferred roadmap work is identified as inference. |
| [SRE](https://viewer.thegram.one/samples/sre.gram) | Operating context, current risks/tasks, incident-response boundaries and explicit evidence. The replacement image-GC thresholds preserve the prior choice and explain the operational reason. |
| [Sales](https://viewer.thegram.one/samples/sales.gram) | Decision evolution: `dec-halden-1yr` becomes superseded, its replacement uses `replaces`, and `ev-halden-deal-desk` implements the new deal choice. Metrics identify denominator, window and measurement source. |
| [Finance](https://viewer.thegram.one/samples/finance.gram) | Close/payment controls, component boundaries, active work and stable metric histories. Prose explains the process around structured facts. |

The sources use standalone record placements, inline mentions, explicit links, filtered task/risk collections, document dashboard views and Mermaid flowcharts. Use the applicable pattern only after checking the current profile and target renderer. The current cloud rich profile lists collection **list/table**, even though its common example mentions `board`. Dashboard, sparklines, Mermaid and the revision slider belong to supporting viewers/apps, not to the storage transport.

The Sales Slack Connect choice is accepted but lacks an implementing-event link. It does not establish an implementation date or verified execution. The Deal Desk event demonstrates the stronger relationship needed for implementation.

The samples' revision recording times reflect imports, while effective times describe earlier facts. They illustrate temporal representation, not authorization to fabricate a history for a current import. Engineering also has date-only observations; preserve actual precision. Per-era counts with different windows are not automatically comparable samples of one continuous metric.

Do not imitate record counts, revision counts, repeated inspection events or link density as quality targets. Use the body to explain what changed and why, retain uncertainty, and put necessary evidence close to the claims it supports. The recipient should understand purpose, state, reasons, turning points and remaining work without opening every link.
